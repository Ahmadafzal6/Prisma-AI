## 🚀 Quick Start

### 1️⃣ Install
```bash
pip install -r requirements.txt
```

### 2️⃣ Configure
Create `.streamlit/secrets.toml`:
```toml
GROQ_API_KEY = "your_key_here"
```

### 3️⃣ Run
```bash
streamlit run app.py
```

### 4️⃣ Open
```
http://localhost:8501
```
